# 后宫模拟器 (Harem Simulator) - 最小可行性产品 (MVP) 说明文档

本项目系基于 Python 编程语言与 Pygame 框架开发的单机模拟经营类沙盒程序。系统旨在模拟古代君王的生平轨迹，涵盖候选人员筛选、后宫数据管理、繁衍机制及权限交接更迭等完整生命周期体系。

## 🌟 系统核心功能 (Core Features)

- **动态时间推演引擎**：系统内置日、月、年的递进流转机制。玩家可通过触发特定政务或休憩指令推进时间进程，且系统设有年度资源自动结算模块以模拟岁贡的周期性更迭。
- **候选人员生成与筛选机制（选秀）**：启动该模块后，系统将依据预设算法随机生成具备独立背景与隐藏属性（如孕育概率）的候选角色实例，供玩家评估并分配相应的居所及系统位分。
- **角色关系与交互系统**：系统提供多维度的数据管理面板。玩家可执行包括资源赏赐、状态指派及角色强制移除在内的多项指令，上述行为将直接影响相关联角色的数据指标（如好感度、经验值）及存活状态。
- **繁衍与子嗣养成模块**：特定交互行为具有触发繁衍事件的概率。系统将记录对应角色的孕期状态，并于周期届满时触发阻断式命名事件，新生成的子嗣对象将自动归入专属的数据队列进行后续的集中管理。
- **群体交互与环境渲染**：支持多目标角色的群体选择功能。通过触发特定场景的游览事件，系统可批量操作并提升参与对象的各项关系映射参数。
- **状态清算与周期重置（结局判定）**：当指定子嗣实体的数据属性达到预设阈值（如存活时长满 864 天），玩家可触发权限交接指令。系统将依此汇总历史周期内的各项核心数据，输出定性评估结果，并提供状态重置接口以开启新的进程周期。

## 🏗️ 架构设计 (Architecture)

本项目严格遵循 **模型-视图-控制器 (MVC)** 架构模式及**单向数据流**设计原则，有效规避了模块间的循环依赖问题，保障了代码结构的健壮性与可维护性：

```
HaremGame/
│
├── src/
│   ├── main.py                # [入口] 程序主循环与初始化入口
│   ├── config.py              # [配置] 全局静态常量、界面参数与运行设定
│   ├── models.py              # [模型] 核心数据结构 (@dataclass)，确保数据隔离
│   ├── logic.py               # [控制器] 核心业务引擎 (状态更新、数值演算)
│   └── ui_manager/            # [视图与路由] 界面渲染与事件分发管理
│       ├── core.py            # 核心状态机路由与图形库初始化
│       ├── components.py      # 封装的可复用界面组件 (按钮、输入框等)
│       └── scenes/            # 各独立业务场景模块 (主状态、选秀、管理等)
│
├── tests/                     # 自动化测试用例 (pytest) 与手动验收清单
├── requirements.txt           # 环境依赖声明
└── README.md                  # 项目说明文档
```

**数据流向规范**：视图层捕获交互事件 ➡️ 触发逻辑层 (`logic.py`) 进行业务处理 ➡️ 变更模型层 (`models.py`) 的全局状态 ➡️ 视图层基于更新后的状态重绘界面。

## 🚀 部署与运行指南 (Deployment & Execution)

**环境要求**：Python 3.8 或更高版本。

1. **获取项目代码**至本地环境。
2. **配置运行依赖**： 在终端 (Terminal) 环境下，进入项目根目录并执行以下指令：

   ```
   pip install -r requirements.txt
   ```
   *(注：当前阶段的核心外部依赖仅为 `pygame` 库)*
3. **启动主程序**：

   ```
   python src/main.py
   ```
