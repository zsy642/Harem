后宫游戏手动测试清单 (Manual UI Checklist)

本清单用于在 Pygame 开发阶段验证界面展示、交互反馈以及动画逻辑。

1. 基础资源渲染 (Assets Loading)

[ ] 占位背景：主界面、宫殿、仓库等场景是否正确加载 tmp1.png，且无拉伸变形。

[ ] 占位立绘：妃嫔和子女详情页是否正确加载 tmp2.png，位置是否居中或符合设计。

[ ] 资源缺失处理：若图片路径错误，控制台是否有明确报错，程序是否能正常运行（显示占位色块）。

2. 场景切换状态机 (Scene Navigation)

[ ] 主循环响应：修改 GameState.current_state，界面是否能瞬间从“主界面”切换至对应场景。

[ ] 返回按钮：所有子场景（后宫、仓库、选秀）是否都有“返回”按钮，且能正确回到主界面。

[ ] 结局拦截：传位后进入 game_over 状态，是否屏蔽了所有其他导航操作，仅保留“重玩”按钮。

3. 时间与数值交互 (Real-time Feedback)

[ ] 睡觉结算：点击“睡觉”，屏幕上方显示的日期（年/月/日/时）是否立即刷新，小时是否归零。

[ ] 按钮置灰：当 GameState.hour >= 21 时，“侍寝”和“游玩”按钮是否变灰或不可点击。

[ ] 属性即时更新：赠送礼物后，角色信息面板上的“宠爱值”数字是否实时跳变。

4. 强制交互弹窗 (Modal/Popup Testing)

[ ] 生产命名：模拟怀孕到期过夜，屏幕中心是否强制弹出文本输入框。

[ ] 输入拦截：在命名弹窗显示时，点击背景中的其他按钮（如设置、导航）是否无效。

[ ] 非法字符处理：在命名框输入特殊符号或空字符串，系统是否有提示或默认处理（如“未命名”）。

5. 列表与排序 (List UI)

[ ] 沉底逻辑：手动将一名妃子 health 改为 0，重新打开宫殿名单，该妃子是否名字带“(死)”并排在最后。

[ ] 隐藏已故：勾选“隐藏已故”复选框，名单中是否立刻滤除了健康值为 0 的角色。

[ ] 分页/滚动：若妃子超过 8 名，名单列表是否支持翻页或滚动（若 MVP 支持）。

6. 游戏流程闭环 (End-to-End)

[ ] 传位通关：选定成年子女传位，是否显示结局文字，点击“重新开始”后，数据是否重置为 1年1月1日。
