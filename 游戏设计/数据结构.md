##### 使用 Python 自带的 @dataclass 装饰器

---

### 1. 全局游戏状态 `GameState`

`游戏“大脑”，统管时间、界面以及所有实体容器。`


| 字段                      | 类型              | 说明                                                                                          |
| ------------------------- | ----------------- | --------------------------------------------------------------------------------------------- |
| `year`                    | `int`             | 当前年份                                                                                      |
| `month`                   | `int`             | 当前月份（满 12 进位）                                                                        |
| `day`                     | `int`             | 当前天数（满 4 进位）                                                                         |
| `hour`                    | `int`             | 当前小时（满 24 进位）                                                                        |
| `current_state`           | `str`             | 当前界面标识，如`"main"`、`"harem"`、`"warehouse"`、`"game_over"`                             |
| `rank_list`               | `List[Rank]`      | 所有已定义的位分对象列表                                                                      |
| `concubine_list`          | `List[Concubine]` | 已入宫的妃嫔列表                                                                              |
| `child_list`              | `List[Child]`     | 所有子女列表                                                                                  |
| `palace_list`             | `List[Palace]`    | 所有宫殿列表                                                                                  |
| `item_list`               | `List[Item]`      | 仓库物品列表                                                                                  |
| `draft_pool`              | `List[Concubine]` | 当前选秀界面临时刷出的待选妃嫔（最多 3 人），确认收入后移入`concubine_list`                   |
| `available_travel_places` | `List[str]`       | 当前可用的游玩地点名称列表（全局配置）                                                        |
| `picture_library`         | `Dict[str, str]`  | 立绘库映射表，key 为图片 ID，value 为资源路径（仅存路径或 ID 关联，实际图片由资源管理器加载） |
| `family_name`             | `str`             | 家族姓氏（玩家开局自选），后续所有孩子默认从该姓                                              |

> 1. **存档说明：** 保存游戏时将整个 `GameState` 序列化为一个 JSON 文件，日志列表等一并写入，无需为每个角色单独维护 JSON 文件。
> 2. **游戏重置:** 在传位操作后，将 current_state 置为 "game_over"。当状态为 "game_over" 时，UI 引擎清空当前画面，并仅渲染一个“重新开始游玩”按钮

### 2. 妃嫔类 `Concubine`


| 字段                       | 类型         | 说明                                                                                                                               |
| -------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `id`                       | `str`        | 唯一标识                                                                                                                           |
| `name`                     | `str`        | 妃嫔姓名                                                                                                                           |
| `title`                    | `str`        | 封号，如“华”                                                                                                                     |
| `rank`                     | `str`        | 当前位分名称，如“贵人”、“嫔”                                                                                                   |
| `age`  | `int`  | 年龄,入宫时默认16 |
| `favor`                    | `int`        | 宠爱值                                                                                                                             |
| `experience`               | `int`        | 经验值，侍寝增加，作为手动调整位分的参考                                                                                           |
| `personality`              | `str`        | 性格描述                                                                                                                           |
| `health`                   | `int`        | 健康值,为0时角色死亡，其名字旁标注“死”字，并从 moved_list 中移除，但保留在全局的 concubine_list。此后该角色年龄停止增长且无法交互。 |
| `pregnancy_rate`           | `float`      | 怀孕概率，0~1                                                                                                                      |
| `pregnancy_days_remaining` | `int`        | 怀孕剩余天数，初始为 -1（未孕）；触发怀孕设为 36，每天减 1，减到 0 时生产                                                          |
| `palace`                   | `str`        | 当前居住宫殿名称，初始为`"储秀宫"`（可变更）                                                                                       |
| `picture`                  | `str`        | 立绘 ID，对应`picture_library` 中的键                                                                                              |
| `log`                      | `List[dict]` | 个人日志列表，运行时用列表存储，例如`[{'time': '1年3月', 'event': '初次侍寝'}]`                                                    |

### 3. 子女类 `Child`


| 字段           | 类型           | 说明                                                                                                                       |
| -------------- |--------------| -------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `str`        | 唯一标识                                                                                                                   |
| `name`         | `str`        | 子女姓名                                                                                                                   |
| `gender`       | `str`        | 性别                                                                                                                       |
| `mother_id`    | `str`        | 生母的唯一 ID                                                                                                              |
| `title`        | `str`        | 封号                                                                                                                       |
| `favor`        | `int`        | 宠爱值                                                                                                                     |
| `health`       | `int`        | 健康值,为0时角色死亡，其名字旁标注“死”字，并从 moved_list 中移除，但保留在子女列表中。此后该角色年龄停止增长且无法交互。 |
| `intelligence` | `int`        | 聪慧值                                                                                                                     |
| `age_days`     | `int`        | 存活总天数。每 48 天界面年龄 +1；达到 864 天（18 岁）加入传位候选列表                                                      |
| `palace`       | `str`        | 固定居住宫殿`"重华宫"`，不可变更,若死亡从`"重华宫"`名单移除                                                                |
| `picture`      | `str`        | 立绘 ID                                                                                                                    |
| `log`          | `List[dict]` | 个人日志列表，格式同妃嫔                                                                                                   |

### 4. 物品类 `Item`

| ------------- | ----- | -------------------------------------- |
| `name`        | `str` | 物品名称                               |
| `quantity`    | `int` | 当前数量（每年固定事件为每种物品 +50） |
| `favor_bonus` | `int` | 赠送给妃嫔/子女时增加的宠爱值          |

---

### 5. 宫殿类 `Palace`


| 字段         | 类型        | 说明                               |
| ------------ | ----------- | ---------------------------------- |
| `name`       | `str`       | 宫殿名称                           |
| `capacity`   | `int`       | 最大入住人数（只能增加，不可减少） |
| `moved_list` | `List[str]` | 已入住妃嫔的ID列表      |

- 当前入住人数始终等于 `len(moved_list)`，避免数据不同步。
- 储秀宫和重华宫设定 `capacity` 为极大值（或 `-1` 表示无限），`moved_list` 可任意增长。

---

### 6. 位分类 `Rank`


| 字段        | 类型  | 说明                                     |
| ----------- | ----- | ---------------------------------------- |
| `name`      | `str` | 位分名称，如“皇后”、“贵妃”、“贵人” |
| `limit`     | `int` | 该位分最大可容纳人数（-1为无限制）       |
| `favor_req` | `int` | 晋升至此位分所需的最小宠爱值             |

> **规则说明：**
> 玩家调整位分设置时，只比较容量与人数。若设置导致 `capacity < num`，游戏**不做额外处理**，仅按新容量显示（现有妃嫔不会被强制降位）。

### 7. 补充说明（全局静态资源）

以下内容适合作为游戏常量或资源表，不直接放入运行时数据类，但可在 `GameState` 中引用或单独加载。

- **立绘库映射表** (`picture_library`)
  类型：`Dict[str, str]`
  示例：`"pic_001": "assets/portraits/consort_01.png"`
  妃嫔/子女的 `picture` 字段存储键名。
- **游玩地点列表** (`available_travel_places`)
  类型：`List[str]`
  示例：`["御花园", "太液池", "清凉殿"]`
  用于出游选择界面。
- **选秀生成规则**
  每次选秀调用时，随机生成 3 个临时 `Concubine` 对象存入 `draft_pool`，玩家确认后移入 `concubine_list`。
